# 🍳 Frontend Mentor - Recipe Card Challenge

Welcome to my repository for the **Recipe Card Challenge**! This project was completed as part of my vocational web designing coursework during my first year as a B.Sc. Computer Science student. 

The goal of this challenge was to build a clean, responsive recipe card component using semantic HTML and custom CSS styles, matching a professional design brief.

---

## 🚀 Features & Learning Outcomes
* **Semantic HTML5:** Structured text layouts utilizing clean containers, headings, and paragraph blocks.
* **Custom CSS Styling:** Leveraged modern typography settings, margins, padding, and subtle shadow elements to match the design card blueprint.
* **Version Control:** Practiced clean repository creation, staging files, and tracking daily code progress on GitHub.

## 🛠️ Built With
* **HTML5** - For clean structure and semantic markup
* **CSS3** - For layout design, colors, and styling
* **Visual Studio Code** - Primary code editor

## 📈 My Growth Path
This project marks my very first steps into front-end design workflows! Building this card helped me understand how design blueprints translate into live code, preparing me for more complex layouts as I progress through my computer science degree.
